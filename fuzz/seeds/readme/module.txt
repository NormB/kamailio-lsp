Example Module

1. Admin Guide

   1.1. Overview

   The module keeps a counter.

   1.2. Parameters

        1.2.1. counter_start (int)

   The first value of the counter.

   Default value is 0.

        1.2.2. counter_name (str)

   The name the counter is shown under.

   1.3. Functions

        1.3.1. count_up(step)

   Adds step to the counter.

Chapter 2. Database parameters

   2.1. db_url (str)

   Where the counter is stored.
